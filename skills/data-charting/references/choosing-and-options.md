# 选型与配置指南

两部分：**上半部分讲每种图适合什么、不适合什么**，**下半部分讲 option 怎么配、有什么效果**。

下半部分的每个片段都由 `scripts/verify-option-effects.mjs` 实测过，验证的不只是「能渲染」，
还包括「产物与不加该片段的基准图不同」—— 专门抓那种写了等于没写的配置。

---

# 上篇：每种图适合什么

## 直角坐标系

### `bar` 柱状图

**适合**：离散类目之间比大小。类目数在 3~12 之间效果最好。

**不适合**：
- 类目超过 15 个 —— 改用横向条形图（见下篇的 `horizontal`），或者先取 Top N
- 表达占比 —— 那是饼图的活，柱状图读者会去比高度而不是比份额
- 连续时间序列 —— 用折线，柱子会让读者以为各时间点是独立的

**常见误用**：y 轴不从 0 开始。柱状图靠高度传达数值，截断基线会成倍夸大差距。
只有在明确标注的情况下才用 `yAxis.scale`。

### `line` 折线图

**适合**：连续变化的趋势，尤其是时间序列。多条系列对比走势也很合适。

**不适合**：
- 类目之间没有顺序关系时 —— 折线会暗示一种并不存在的连续性
- 系列超过 5 条 —— 线会缠成一团，改用小多图或只保留关键的几条

**常见误用**：数据点稀疏（少于 4 个）时用折线。两三个点连成线，趋势是脑补出来的。

### `scatter` 散点图

**适合**：看两个数值变量之间有没有关系，以及识别离群点。

**不适合**：一个维度是类目而不是数值时 —— 那种情况柱状图更直接。

**扩展**：要表达第三个维度就逐点指定 `symbolSize` 做成气泡图。
注意 `symbolSize` 不能写成回调函数，必须每个点单独给数值。

### `heatmap` 热力图

**适合**：两个类目维度交叉，看哪一格数值高。典型场景是「星期 × 时段」这类。

**不适合**：某一维的类目太多（超过 20），格子会小到看不清。

**必配**：`visualMap`。不配的话所有格子一个颜色，图就没意义了。模板会自动按数据范围配好。

### `boxplot` 箱线图

**适合**：比较几组数据的分布形态 —— 中位数、四分位距、离群程度。

**注意**：要传的是**已经算好的五数概括**（min / Q1 / median / Q3 / max），不是原始观测值。
传原始数据不会报错，但画出来是错的。

### `candlestick` K 线图

**适合**：金融价格的开高低收。

**不适合**：非金融数据。这个图形的四个数值有固定语义，套用到别的场景读者会误读。

## 非直角坐标系

### `pie` 饼图

**适合**：**一个整体**分成**少数几块**（2~6 块）看占比。

**不适合**：
- 分块超过 7 个 —— 小扇区无法区分，改用横向条形图
- 比较两个时间点的构成 —— 两个饼图并排很难比，改用堆叠柱状图
- 各部分之和不构成一个整体时 —— 饼图隐含「加起来是 100%」的语义

**常见误用**：用饼图比较大小接近的两块。人眼判断角度的精度远低于判断长度。

### `funnel` 漏斗图

**适合**：**线性**的、逐级递减的流程，比如注册转化。

**不适合**：有分支或回流的流程 —— 那种用桑基图。漏斗图的形状本身就假设了单向递减。

### `radar` 雷达图

**适合**：一到三个对象在 4~8 个维度上的综合表现对比。

**不适合**：
- 对象超过 3 个 —— 图形叠在一起无法分辨
- 维度之间量纲差异大且未归一化 —— 形状会被大量纲的维度主导

**注意**：模板会按各指标的最大值自动设 `max`，所以各轴的刻度是独立的。
需要统一刻度时用 `optionOverrides` 覆盖 `radar.indicator`。

### `parallel` 平行坐标图

**适合**：多个样本在多个数值维度上的对比，适合发现聚类和异常样本。

**不适合**：样本超过几十条 —— 线会糊成一片。

### `treemap` / `sunburst` 层级图

**适合**：层级结构下各部分的占比。`treemap` 用面积，适合层级浅、需要比较大小；
`sunburst` 用同心环，适合展示层级本身。

**不适合**：需要精确读数 —— 面积和角度都不适合精确比较。

**数据形式**：都用 `[层级路径, 数值]`，路径用 `/` 分隔，例如 `"华东/上海"`。

## 结构型

### `sankey` 桑基图

**适合**：有**分支**的流量走向，能同时表达流向和流量大小。

**不适合**：
- 单向线性流程 —— 漏斗图更简洁
- 有环的关系 —— 桑基图要求无环，有环会画得很乱

**注意**：`links` 里的 `source` / `target` 必须是 `nodes` 里出现过的 `name`，
写错名字不会报错，那条边会直接消失。

### `graph` 关系图

**适合**：实体之间的连接关系，力导向布局会自动排布。

**不适合**：节点超过 50 个 —— 力导向的结果会变成毛球，改用矩阵或分层布局。

**扩展**：`node.value` 越大节点画得越大，可以用它表达节点的重要度。

### `tree` 树图

**适合**：明确的层级归属，比如组织架构、目录结构。

**不适合**：一个节点有多个父节点的情况 —— 那不是树，是图，用 `graph`。

## 坐标系型

### `calendar` 日历图

**适合**：以「天」为粒度、跨度在一年上下的时间序列。一格一天，一眼能看出周末效应、
季节性、以及连续中断的那几段。

**不适合**：
- 时间粒度不是天 —— 小时级用 `heatmap`（星期 × 时段），月度用 `bar`
- 只想看总量走势 —— 折线更直接，日历图强的是「哪一天」而不是「涨了多少」

**注意**：第一维必须是 `YYYY-MM-DD`。ECharts 对认不出的日期不报错，只是把该点丢掉，
结果是一张完全空白的日历。模板会主动校验并报错。跨年数据自动按年拆成多个日历，不用自己分组。

### `liquid` 水波图

**适合**：**一个**比例，而且读者只需要「满没满」这个印象。
进度看板、容量水位是它仅有的合理场景。

**不适合**：
- 要比较多个指标 —— 三个球并排远不如三根柱子好比
- 要看变化 —— 它没有时间维度
- 要读精确值 —— 球里只能塞一个百分数，小数位会挤掉

**注意**：来自第三方扩展 `echarts-liquidfill`，不在官方示例库里，
所以 gallery 下没有它的例子。

### `matrix` 矩阵图

**适合**：行列都是类目、每格一个数、而且**要逐格读数**的交叉表。
混淆矩阵和相关系数矩阵是最典型的两个。

**不适合**：
- 类目多到读不完每一格 —— 那就该用 `heatmap`，看色块分布而不是读数
- 行列之间没有对应关系 —— 那只是一张普通表格，用文字表格更省事

**与 `heatmap` 的区别**：数据形状完全一样，区别在表现。`matrix` 画出带行列表头的
表格并默认开标签，`heatmap` 画的是连续色块。要读数用 `matrix`，要看分布用 `heatmap`。

# 下篇：option 怎么配，有什么效果

所有片段放进 `generate_chart` 的 `optionOverrides`，或直接写进 `render_option` 的 `option`。

**合并规则**：对象递归合并，**数组按索引逐项合并**。
所以 `{"series":[{"stack":"t"}]}` 只影响第一条系列，且不会冲掉它的 `data`。
有几条系列要改，就给几个条目。

## 布局与留白

| 配置 | 效果 |
|---|---|
| `{"grid":{"left":90,"right":60,"top":80,"bottom":90}}` | 调整绘图区四边留白。轴标签被截断时加大对应方向的值 |
| `{"grid":{"containLabel":true}}` | 让 grid 自动把轴标签算进留白，长类目名不再被裁掉 |

## 标题与图例

| 配置 | 效果 |
|---|---|
| `{"title":{"left":"left"}}` | 标题左对齐。默认居中，左对齐更像报表 |
| `{"legend":{"top":10,"right":10,"bottom":"auto","orient":"vertical"}}` | 图例移到右上角竖排，把底部空间让给数据 |
| `{"legend":{"show":false}}` | 隐藏图例。只有一条系列时图例是噪音 |

## 坐标轴

| 配置 | 效果 |
|---|---|
| `{"xAxis":{"axisLabel":{"rotate":30,"interval":0}}}` | 类目标签旋转并强制全部显示，解决长标签重叠 |
| `{"xAxis":{"name":"月份"},"yAxis":{"name":"万元","nameLocation":"end"}}` | 给坐标轴加单位说明 |
| `{"yAxis":{"min":0,"max":250}}` | 固定 y 轴范围。**多图对比时必须固定**，否则各图刻度不同会误导 |
| `{"yAxis":{"scale":true}}` | 不强制从 0 开始，放大相对差异。**柱状图慎用**，会夸大差距 |
| `{"yAxis":{"axisLabel":{"formatter":"{value} %"}}}` | 刻度加单位。用字符串模板，不能用函数 |
| `{"yAxis":{"splitLine":{"show":false}}}` | 去掉横向网格线，画面更干净 |

## 系列通用

| 配置 | 效果 |
|---|---|
| `{"series":[{"stack":"总量"},{"stack":"总量"}]}` | 堆叠。**有几条系列就要给几个条目**，少给一个那条就不堆叠 |
| `{"series":[{"label":{"show":true,"position":"top"}}]}` | 柱顶显示数值 |
| `{"series":[{"label":{"show":true,"position":"inside","formatter":"{c} 万"}}]}` | 标签放柱体内并带单位。`{c}` 是数值，`{b}` 是类目名，`{d}` 是百分比 |
| `{"series":[{"itemStyle":{"borderRadius":[6,6,0,0]}}]}` | 柱顶圆角 |
| `{"series":[{"barWidth":"35%","barGap":"20%"}]}` | 控制柱宽与柱间距。类目少时柱子过宽可用它收窄 |
| `{"color":["#c23531","#61a0a8"]}` | 换整体配色。**放顶层**，各系列按顺序取色 |
| `{"series":[{"itemStyle":{"color":"#34c759"}}]}` | 只改某一条系列的颜色 |

## 折线专属

| 配置 | 效果 |
|---|---|
| `{"series":[{"smooth":true,"areaStyle":{"opacity":0.15}}]}` | 平滑曲线加半透明面积，强调累积趋势 |
| `{"series":[{"step":"end"}]}` | 阶梯折线，适合状态跳变而非连续变化 |
| `{"series":[{"symbol":"none"}]}` | 隐藏数据点标记。点密集时标记会糊成一片 |
| `{"series":[{"lineStyle":{"type":"dashed","width":2}}]}` | 虚线，常用来表示预测值或目标线 |

## 标注

| 配置 | 效果 |
|---|---|
| `{"series":[{"markLine":{"data":[{"type":"average","name":"平均"}]}}]}` | 画均值线，无需自己算 |
| `{"series":[{"markLine":{"data":[{"yAxis":160,"name":"目标"}],"label":{"show":true}}}]}` | 画指定数值的参考线，比如目标值 |
| `{"series":[{"markPoint":{"data":[{"type":"max"},{"type":"min"}]}}]}` | 标出最大值与最小值 |
| `{"series":[{"markArea":{"itemStyle":{"color":"rgba(0,122,255,0.08)"},"data":[[{"xAxis":"2月"},{"xAxis":"3月"}]]}}]}` | 给某区间加背景色块，圈出关注区域 |

## 数据映射与缩放

| 配置 | 效果 |
|---|---|
| `{"visualMap":{"min":0,"max":220,"calculable":true,"orient":"horizontal","left":"center","bottom":0,"inRange":{"color":["#34c759","#ffcc00","#ff3b30"]}},"grid":{"bottom":80}}` | 按数值连续着色并带图例条。**记得同时加大 grid.bottom**，否则图例条会压住 x 轴 |
| `{"dataZoom":[{"type":"inside"},{"type":"slider","bottom":10}],"grid":{"bottom":90}}` | 缩放。**静态图里看不出效果**，只在 `output: "html"` 下可交互 |

## 坐标系变换

| 配置 | 效果 |
|---|---|
| `{"xAxis":{"type":"value","data":null},"yAxis":{"type":"category","data":["1月","2月"]}}` | 横向条形图。类目名长时首选。**`yAxis.data` 必须填真实类目** |
| `{"grid":null,"xAxis":null,"yAxis":null,"polar":{"radius":[30,"72%"]},"angleAxis":{"type":"category","data":["1月","2月"]},"radiusAxis":{},"series":[{"coordinateSystem":"polar"}]}` | 极坐标柱状图。**必须同时把 grid/xAxis/yAxis 置 null** |
| `{"yAxis":[{"type":"value","name":"销量"},{"type":"value","name":"利润"}],"series":[{},{"type":"line","yAxisIndex":1,"smooth":true}]}` | 双 Y 轴。量纲不同的两条系列共存，第二条走右轴并改成折线 |

## 主题与背景

| 配置 | 效果 |
|---|---|
| `{"backgroundColor":"#f5f5f7"}` | 改画布背景色 |
| `{"backgroundColor":"transparent"}` | 背景透明，方便嵌进已有页面 |

内置主题走 `theme` 参数而非 `optionOverrides`，可选 `default` / `dark` / `vintage`。

## 三条容易踩的规则

1. **数组按索引合并。** 改第二条系列必须写成 `{"series":[{}, {...}]}`，
   第一个空对象是占位。直接写 `{"series":[{...}]}` 改的是第一条。
2. **配色放顶层。** `color` 写在 `series` 里只对那一条生效，
   写在顶层才是整体调色板。
3. **加了底部元素就要加 `grid.bottom`。** `visualMap`、`dataZoom` 的滑块默认贴底，
   不腾出空间会和 x 轴标签重叠。
